Bagged Up — getting the website online

Three steps. About five minutes. Nothing to install.

What you need

A computer, internet, and an email address. That's it.

Do this

  1. Save the website file Download Bagged-Up-website.zip and keep it somewhere you'll find again. This file is the website.
  2. Go to Netlify Drop Open app.netlify.com/drop in your browser, then drag the zip file onto the page and let go.
  3. Wait, then sign up free After about a minute you'll get a live website. Create a free account with your email so it's saved to you.

Done — your shop is live. You'll get an address like bagged-up-12345.netlify.app. Share that, or ask about using your own domain name.

The file

Bagged-Up-website.zip The website. This is the only thing you upload.
Two things to remember

Orders arrive on WhatsApp, not through the website. Customers browse and then message you. Check it every day.

Renew your domain every year. If it lapses the site disappears from the internet. This is the #1 way a site "breaks".

Need something changed?

New prices, adding a bag, new photos, changing wording — just message whoever set this up for you. Those are quick changes.

They'll send you a new zip. Drag it onto app.netlify.com/projects to replace the old one. If it ever looks wrong, Netlify keeps every old version and you can go back with one click.
